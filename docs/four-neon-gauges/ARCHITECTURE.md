# Four Neon Gauges architecture

The gauge surface has three layers:

```text
Metric / Great Book evidence
→ governed gauge projection
→ WebGPU arc scene + crisp DOM overlay
```

The WebGPU shader renders cinematic arcs, ticks, confidence, coverage, freshness, warning pulses, and real value motion. The DOM overlay remains authoritative for IDs, labels, native values, deltas, evidence state, and accessibility.
