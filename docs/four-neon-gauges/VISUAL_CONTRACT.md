# Four Neon Gauges visual contract

- exactly four gauges;
- symmetric 2×2 layout;
- each gauge inherits its metric-family color;
- selection and warning use separate halo/motion channels;
- every gauge shows metric ID/name, native value/unit, normalized value or gate state, delta/trend, confidence, coverage, freshness, scope, aggregation, and warning;
- click focuses the corresponding Great Book metric cell;
- double-click requests the catalogue record and normalization profile;
- stale, unknown, and not-applicable gauges remain visible and explicit.
