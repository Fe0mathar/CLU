# Limitations and next steps

- Live Great Book records and live gauge readings are not yet produced by the current CLU_v6 registries; the package provides contracts, projectors, demos, and Dashboard integration seams.
- The Four Neon Gauges use a real WebGPU shader with a DOM truth overlay. Target-host Chrome must validate the final shader/pipeline.
- The Great Book field renderer remains the initial visual core supplied by the preceding package; its authoritative coordinate/projection model is strengthened here.
- The next integration should bind click events from gauges to the matching Great Book metric cell and Operational Console evidence record.
